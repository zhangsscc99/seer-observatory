# ART-SPEC — 美术与音效规范

致敬《赛尔号》的**视觉语言**：圆润的白色未来舱、青色灯带、全息星图、饱和的蓝紫星云。
不使用、不描摹任何原作素材；`docs/reference/bridge-concept.jpg` 只作为氛围参考。

## 2.5 主角机器人模型（Blender → GLB）

主角不再是 primitive 拼块，而是**程序化生成**的 GLB：`public/models/seer.glb`（约 290 KB / 8.7k 三角面），
由 `scripts/build-robot.py` 在无头 Blender 4.2 里生成，可复现（同一脚本 → 同一模型）。

| 项 | 值 |

| 单位 / 朝向 | 米；原点在两脚之间地面；面朝 glTF **+Z**（与旧 primitive 的「面朝 +z」约定一致，`robot.ts` 不再额外旋转） |
| 配色 | 头壳/躯干 `#1A1A1A` 哑光黑；金属环与包边金 `#D9B45B`；波纹管与天线杆 `#808080`；眼/高光 `#FFFFFF` 自发光 |
| 材质（glTF metallic-roughness） | 黑壳 rough 0.35 / metal 0.10；金 metal 0.90 / rough 0.25；灰管 metal 0.80 / rough 0.40；眼 emissive 强度 ≈4（`KHR_materials_emissive_strength`） |

## 2.6 冰环带 `icer`（F601–F603）

调色板：冰蓝 `#8FD0F2`（深）/ 霜白 `#E8F7FF`（中）/ 纯白 `#FFFFFF`（亮），大气雾青 `#9FE6FF`。
地表 = canvas 程序化 equirect 贴图：蓝白斑驳冰壳 + **voronoi 细密多边形裂纹**（jittered grid，F2−F1 边距 → 深蓝裂纹线，
强度随低频噪声起伏）+ 极冠亮区。

环系统（`src/render/rings.ts`，单 mesh、`RingGeometry(1.5R, 2.35R, 192, 4)`，NormalBlending + depthWrite off）：

| 参数 | 值 |
| --- | --- |
| 倾角 | group 绕 x 17°、绕 z 9°；自转由 `uTime` 驱动（角粒纹 0.05 rad/s） |
| 环带 | 3 层 hash→value noise（freq 6 / 15 / 37，权重 .52 / .30 / .18）+ 细颗粒 octave；alpha 基带 0.15–0.90 |
| 卡西尼缝 | t ∈ 0.58–0.66（中心 0.62）alpha → ~0，两侧各 0.01 smoothstep |
| 内外边缘 | t < 0.06 / t > 0.94 各淡出到 0 |
| 前向散射 | `pow(max(dot(viewDir, sunDir), 0), 8)`，背光看环更亮 |
| 行星本影 | 反日方向弧带：投影轴 \|perp\| < R（0.92–1.05R 过渡），落影内乘 0.18（`1.0 − 0.82·umbra`） |
| 冰晶闪点 | 旋转 2D 颗粒 hash 阈值 0.97 + `pow(·,3)`，乘自发光色 `uCol2` |

行星表面（F606）：`day = smoothstep(-0.06, 0.30, ndl)`，`col = albedo·(0.10 + 0.92·day)`——晨昏线收窄、
白天面不再削顶成白，夜面保留 ~0.10 底光不死黑；`ice-ring / ice / gas` 加 `uSpec` 微弱高光
（`pow(dot(n, normalize(v + sun)), 48)·0.18·day`），火山星不加；fresnel 内边缘光只留受光项
`uAtmo·fres·smoothstep(-0.35, 0.30, ndl)`（无基线）。

双层大气 halo（BackSide additive，`uEdge = √(1−1/scale²)`）：宽雾 `1.16R` pow 3.2 gain 0.45 + **窄亮边 `1.05R` pow 6.0 gain 0.5**（峰值更锐）；
只出现在受光侧（`lit = smoothstep(-0.35, 0.30, ndl)`，无基线），晨昏线把 `uAtmo` 调暖 8%（×`(1.08, 1.00, 0.92)`）。
低温雾壳：`1.02R` FrontSide additive，`vnoise3` 随 `uTime` 漂移，向阳面 alpha ≤ 0.12。

## 2.7 气态巨行星 `gas-storm`

- **调色板**：deep `#5A2A14` / mid `#C47A3A` / bright `#FFE6B8`，大气 `#FFC07A`
- **贴图**：1024×512；域扭曲 `qv = v + 0.045*w1 + 0.02*w2`；条带频率 π×6.5 / 14 / 26 / 44，幅度 0.14/0.11/0.065/0.045；两段 smoothstep（0.30–0.62、0.62–0.92）；低频亮度 macro 0.88–1.12；极区 ×0.68 压暗
- **风暴眼**：u 0.62 / v 0.42，椭圆 0.082×0.046，`er<1.4`；对数螺旋臂 + 噪声扰动；0.75–1.05 环带暗褐、核心提亮至米白
- **着色器**：差速流动 u 向 0.006–0.012/s（赤道 jet=1、极区 0.35）、旋涡 0.25 rad/s；夜侧 `albedo*atmo*0.10*(1-day)*limb^1.5`；`uSpec 0.45`
- **halo**：1.16R pow 4.2 gain 0.42 + 1.05R pow 5.5 gain 0.24（只受光侧）
- **采集站**：`r = 0.20R`，offset `(0.35R, 0.72R, -1.05R)`，自转 0.22 rad/s，16 窗光 + 3 暖工灯 + 0.3R 采集缆
- **实测亮度**：cabin 126.06 / 0.01 / 196.32；space 89.55 / 170.12；gas 70.5 / 192.0
- **已知不足（诚实记录，下轮待办）**：特写里采集站剪影偏小、易与飞船轮廓混淆；条带仍偏平滑，缺高频碎云/丝状卷曲；风暴眼偏同心椭圆，螺旋臂不够强；halo 略均匀（缺晨昏线分层散射）。

## 2.8 红巨星系 `red-giant`（M8，F801–F804）

- **调色板**：deep `#7A1C0E`（暗色球面）/ mid `#F26419`（主橙）/ bright `#FFF2D0`（耀斑核），大气/日冕 `#FF8438`；暗沟色 = deep ×(0.42, 0.34, 0.30)
- **位置**：`r = 280` @ `(-480, 160, 1020)`（本星域最大天体，与其余 6 星包围球零重叠）；扫描范围 3.2R ≈ 896
- **光球贴图**（`redGiantTexture`，1024×512 equirect，seed 89）：两层抖动 Voronoi——粗 12×6 / 细 40×20（3.33× 尺度差），用 `F2-F1` 边距画暗沟、`F1` 距离做米粒内部亮心；`nWarp` 16 频率域扭曲打破规则感；`nMacro` 8 频率亮度 0.88–1.12；16 个随机耀斑核（`#FFF2D0`，半径 3–9 px 软边）；极区 ×0.82、赤道 ×1.06
- **着色器**（`RED_GIANT_FRAG`，自发光，无 `uSun` 漫反射项）：
  - 双层 UV 采样 `mix(base, boil, 0.18)`，漂移速度 `flow = uTime*0.02`（u 向 ±0.14、v 向 ±0.09，加正弦抖动）
  - 临边昏暗：`limb = pow(1-dot(N,V), 1.6)` → 亮度 `mix(1, 0.34, limb)`，颜色 `mix(白, #DB3D0F, limb)`（边缘更暗更红）
  - 耀斑核加强：`smoothstep(0.68, 0.96, albedo.g) * 0.85`
  - 色球边缘：`pow(1-dot(N,V), 4.2) * atmo * (1.15, 0.48, 0.16) * 0.42`
  - `uGlow = 1.7`，ACES tone mapping
- **日冕 halo**（自发光版 `haloShell(..., lit=false)`）：1.16R `pow 1.9` gain 0.62 + 1.06R `pow 3.8` gain 0.72（`#FFB45C`）
- **日珥弧**（`buildProminences`）：5 条环带（span 0.28–0.36 rad、apex 0.21–0.30R、宽 0.052–0.068R），加色混合，颜色 `mix(#F2380D, #FFC257, ...)`，`sin` 流纹 + 呼吸 `1±0.18`，脉动幅度 4.5%
- **尘埃幕**（`buildDustVeil`）：2.6R 双面壳，`ndv` 环带遮罩（中心 0.96–0.34 平滑过渡，保持恒星面清晰），三层 3D 噪声 5.5/26/78 频率，alpha ≤ 0.34；外加 420 颗 1.45R–2.65R 逆光尘点（`pow(rnd,0.72)` 分布）
- **耀斑 billboard**：`flareTexture()` 染 `#FF9640`、opacity 0.78、尺寸 5.8R（随 `uTime` 缓慢旋转/呼吸）
- **照明**：恒星位置挂 `PointLight(0xff8438, 1200, 3.8R, decay 0.85)`，只照亮近景飞船/舱外，不污染舱内
- **实测亮度**（2026-11-21 M8）：cabin `126.07 / darkFrac 0.01 / p95 196.24`；space `89.67 / p95 170.20`；特写 red 横屏 `87.9 / p95 217.1`，竖屏 `105.5 / p95 228.5`
- **已知不足（下次优先，已入 FEATURES T5/T6）**：米粒尺度偏大、暗沟过宽 → 特写读成「干裂泥地」而非沸腾对流；halo 把临边昏暗复亮；日珥弧与尘幕在 2.55R 机位几乎看不见；飞船受光偏平（缺明确明暗交界线）。

## 2.9 双星系 `binary`（M9，F901–F905）

- **调色板**：
  - 行星 `binary`（`双子星域`）：冷蓝 `#3A7FD5` / 暖橙 `#F08C3A` / 白 `#F2F7FF`，大气 `#D9E8FF`；深冷底 `#163E84`、深暖底 `#682A12`
  - 主星 `binary-a`（冷白）：`#BFE0FF`，`r = 88`，`intensity = 2.2`，位置 `(380, 560, -1960)`（距原点 ~2073）
  - 伴星 `binary-b`（暖橙）：`#FFB066`，`r = 70`，`intensity = 1.5`，位置 `(1460, -480, -1760)`（距原点 ~2337）
  - 行星位置：`(1100, -30, -520)`，`r = 135`（距其余 7 星均 > 半径和 + 100，在 `SECTOR_RADIUS = 1500` 内）
- **贴图配方**（`binaryTexture`，1024×512 equirect，seed 97，零外部素材）：

  - 第二盏 `DirectionalLight`（暖橙 `#FFB066`，满强度 `1.5`）挂在 `near` 组（舱内 `near.visible = false` 彻底隔离），方向从伴星指向场景中心

  - 外层双色 halo：宽雾 `1.16R`（pow 3.0, gain 0.44）+ 窄亮边 `1.05R`（pow 5.4, gain 0.36）
- **星图台全息球与 HUD**：选中 `binary` 时 `cabin.setHoloColor(0xbfe0ff, 0xffb066)` 切换冷暖双色全息球与双轨光环；靠近或选中时顶部警示条用青色系显示 `双星光子场·回充 ×1.3`（不用红/金）

- **双恒星盘面 / 耀斑与行星云带微调（F906）**：主星视觉半径 `1.12R`（`844×390` 约 32 px）配 `1.24R/1.58R` 日冕壳 + `7.2R` 径向日冕 + `9.5R` 冷蓝耀斑（opacity 0.88）；伴星 `0.86R`（约 22 px ≥ 18 px）配 `1.22R/1.50R` 日冕壳 + `5.6R` 径向日冕 + `6.8R` 暖橙耀斑（opacity 0.78），`BINARY_STAR_FRAG` 强化白热核心与饱和色温外缘；行星在晨昏环带两侧各叠 3 条异速反向细卷云带，外层 halo 柔化为 `1.14R`（pow 3.8, gain 0.26）+ `1.045R`（pow 6.5, gain 0.22），夜侧底光 `vec3(0.085,0.095,0.125) ≥ 0.05`

## 3. 可读性要求

硬指标（`scripts/measure-look.mjs`，844×390 横屏卡阈值；390×844 竖屏只记录）：

```
舱内:  mean 110..135     darkFrac(<10) <= 0.15      p95 >= 120
太空:  mean 45..95                                p95 >= 120
```

当前实测（2026-11-20，F606 后，844×390）：舱内 mean **126.2**、top30 116.3、p95 196.6、darkFrac 0；
太空 mean **89.4**、p95 169.6；icer 特写 mean 87.5 / p95 165.4（信息项）。竖屏记录：舱内 141.2 / 太空 88.4 / icer 84.6（信息项，不卡阈值）。

注：`measure-look.mjs` 的截图在 4 核无 GPU 的 SwiftShader 下常超过默认 30 s，脚本已改为 `timeout: 120000` + 最多 3 次重试；
另外 `focusPlanet('icer')` 调试钩子把船放到 3.2R、环平面上方 12°、偏离反日方位 ~60° 拍 3/4 冰环带特写——
晨昏线、卡西尼缝与行星本影弧都应在画面里（`icer-{844x390,390x844}.png`，信息项）。

设计要求：

1. **太空永不纯黑**：星云基底最低也是靛蓝，暗尘带是乘法压暗而不是归零。
2. **主角轮廓**：机器人 / 飞船是画面里最亮的白，背后永远有青色发光件（背包灯 / 引擎）与接触阴影。
3. **目标可见**：出生点正对星图台，绿色全息球在第一帧就位于画面中上部；地面有青绿箭头指向它。
4. **HUD 极简**：左上地点 + 一句目标；右下一个主按钮（舱内「启航」、太空「推进」）；按钮 ≥ 48 px，
   避开安全区；竖屏 390×844 可单手操作。
5. 发光只用三种颜色（青 / 青绿 / 白），不出现红色警示色。
