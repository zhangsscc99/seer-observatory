# ART-SPEC — 美术与音效规范

致敬《赛尔号》的**视觉语言**：圆润的白色未来舱、青色灯带、全息星图、饱和的蓝紫星云。
不使用、不描摹任何原作素材；`docs/reference/bridge-concept.jpg` 只作为氛围参考。

## 1. 调色板（`src/render/palette.ts`）

| 名称 | Hex | 用途 | 占比 |
| --- | --- | --- | --- |
| hullWhite | `#F2F6FA` | 舱壁、控制台、机器人、飞船外壳 | 主色 ~55% |
| hullShade | `#C9D4E0` | 端盖、扶壁、次级壳体 | ~15% |
| panelGrey / metalDark | `#8E9DB0` / `#3A475A` | 金属饰条、踢脚、格栅 | ~8% |
| cyan | `#38E1FF` | 灯带、眼睛、关节、屏幕读数、HUD 描边 | 发光强调 ~10% |
| blueCarpet | `#1C3F9E` | 座椅区条纹地毯、屏幕底色 | ~8% |
| holoGreen | `#4DFFA0` | **仅**全息地球、星图台光环 | ≤ 3% |
| tealAccent | `#2FE6B8` | 状态小点、引导箭头、「启航」按钮 | ≤ 2% |
| 星云 | 靛蓝 `#0A1030` → 蓝 `#2A7AF0` → 紫 `#7A48D8` | 天空 | — |
| sun | `#FFF1C8` | 恒星、耀斑（全场唯一暖色光源） | — |

规则：舱内是**冷白 + 青蓝**；绿色只留给"要去的地方"（星图台），所以它在任何机位都是视觉落点。
暖色只出现在太空（太阳、气态行星、火山星），与舱内形成对比。

## 2. 材质配方（`src/render/materials.ts`）

| 材质 | 模型 | 参数 | 说明 |
| --- | --- | --- | --- |
| hull（塑料壳） | Standard | rough 0.42 / metal 0.04 | 柔和高光，白而不反光 |
| hullShade | Standard | rough 0.50 / metal 0.06 | 与 hull 拉开一档明度 |
| metal（合金饰条） | Standard | rough 0.28 / metal 0.85 | 反射星云环境贴图，偏蓝 |
| metalDark | Standard | rough 0.40 / metal 0.70 | 踢脚、发射器 |
| visor | Standard | rough 0.08 / metal 0.60 | 机器人面罩、飞船座舱盖 |
| cushion | Standard | rough 0.85 / metal 0 | 座椅软垫（唯一的"布"） |
| 地砖 | Standard + map/emissiveMap/roughnessMap | metal 0.22，瓷砖 rough≈0.35，地毯 rough≈0.8，envMapIntensity 1.6 | 细微反射来自星云 cubemap |
| 发光体（灯带、眼睛、顶灯） | Basic，颜色 ×1.3–2.0 | 不受光 | ACES 后仍读作光源 |
| 全息 | Basic 线框 + 半透明内核 + 加色光锥 | 透明度带闪烁 | — |
| 行星 | ShaderMaterial | 贴图 × 昼夜 + fresnel 内边缘光 | 外加 BackSide 加色光晕壳（1.16R） |

光照：舱内 = 半球光 1.05 + 顶部方向光 1.15 + 星图台绿色点光 + 中央冷色点光；
太空 = 太阳方向光 2.6 + 蓝紫半球补光 1.25。渲染器 ACES Filmic，曝光 1.0，sRGB 输出。

## 3. 可读性要求

硬指标（`scripts/measure-look.mjs`，844×390，舱内与太空**都**要过）：

```
mean >= 55      top30 >= 45      darkFrac(<10) <= 0.20      p95 >= 140
```

设计要求：

1. **太空永不纯黑**：星云基底最低也是靛蓝，暗尘带是乘法压暗而不是归零。
2. **主角轮廓**：机器人 / 飞船是画面里最亮的白，背后永远有青色发光件（背包灯 / 引擎）与接触阴影。
3. **目标可见**：出生点正对星图台，绿色全息球在第一帧就位于画面中上部；地面有青绿箭头指向它。
4. **HUD 极简**：左上地点 + 一句目标；右下一个主按钮（舱内「启航」、太空「推进」）；按钮 ≥ 48 px，
   避开安全区；竖屏 390×844 可单手操作。
5. 发光只用三种颜色（青 / 青绿 / 白），不出现红色警示色。

## 4. 音效事件表（`src/audio/sfx.ts`，全部 WebAudio 合成）

| 事件 | 触发 | 合成 | 时长 |
| --- | --- | --- | --- |
| `footstep` | 机器人每走 0.55 m | 带通噪声 900→300 Hz + 190→120 Hz 正弦"嗒" | 70 ms |
| `prompt` | 进入星图台交互范围 | 880 Hz → 1318 Hz 两音上行 | 270 ms |
| `confirm` | 点击「开始探索」 | 三角波 660 / 990 / 1320 琶音 | 360 ms |
| `launch` | 启航成立 | 锯齿 70→520 Hz 蓄力 + 正弦 220→1760 + 带通噪声 200→3200 Hz 呼啸 | 1.3 s |
| `dock` | 返航切回舱内 | 正弦 1040→520 下行 + 低通噪声 | 0.6 s |
| `bump` | 飞船撞上行星 / 空间站 | 正弦 110→40 + 低通噪声 | 0.3 s |
| `deny` | 不在范围内按启航 | 方波 196→150 | 140 ms |
| 舱内环境低鸣（循环） | 舱内常驻，太空降到 25% | 55 / 82.6 / 110.4 Hz 正弦 + 420 Hz 带通气流噪声 | ∞ |
| 推进器嗡鸣（循环） | 太空常驻；启航蓄力时预热 | 两个锯齿（55–115 / 82–174 Hz 随速度）+ 噪声 → 低通（220–2400 Hz 随速度 / 推进） | ∞ |

规则：AudioContext 在首次用户手势内创建；总线过压缩器；静音状态存 `localStorage['seer.muted']`，
右上角 ♪ 按钮 / `M` 键切换。
