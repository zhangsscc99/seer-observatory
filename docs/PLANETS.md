# PLANETS — 星球/星域进度表

方向：**多搞几个星球出来探索**。每轮挑一个「未完成的星球/星域」做成**可到达、可扫描、有辨识度**的内容，
并在星图台上可选（不同选择真的改变场景：配色 / 行星数 / 危害类型）。

每轮的最低交付（缺一不算完成）：
1. 一个星球/星域的地表或轨道场景（程序化生成，零外部素材）
2. 交互链路：靠近 → 扫描进度 → 资源/日志条目（写 `localStorage` + HUD 档案）
3. 星图台可选，选择改变场景
4. 移动端可玩：竖屏可用、按钮 ≥48px、无滚动条、DPR ≤ 2
